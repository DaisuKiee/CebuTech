# CebuTech - BSIT Batch 2023-2027

![CebuTech](public/img/ctulogo.png)

## 🎓 About CebuTech

**CebuTech** is the official showcase website for the BSIT (Bachelor of Science in Information Technology) Batch 2023-2027 from **Cebu Technological University (CTU)**. We are a community of 42 passionate tech enthusiasts, innovators, and future leaders in the field of Information Technology.

🌐 **Live Website**: [https://cebutech.digital](https://cebutech.digital)  
📍 **Location**: Cebu, Philippines  
🏫 **Institution**: Cebu Technological University (CTU)

## ✨ What We Showcase

- **42 Talented Students** - Meet the brilliant minds shaping the future of technology
- **5+ Major Projects** - Explore our innovative solutions and applications
- **Comprehensive Programs** - Discover our academic journey and specializations
- **Batch Information** - Learn about our cohort and achievements

## 🚀 Our Projects

1. **Daanbantayan Paradise** - Tourist booking platform for Daanbantayan, Cebu
2. **SSG Innovoice** - Digital suggestion box system for student government
3. **GPTracker** - Group payment tracking platform with Firebase integration
4. **OnBoard** - Community management platform with Filipino Bayanihan spirit
5. **SSG Office Assistant App** - Office management system prototype

## 💻 Tech Stack

- **Frontend**: React 18
- **Backend**: Express.js
- **Styling**: Custom CSS with modern dark theme
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Deployment**: Vercel

## 🛠️ Getting Started

### Development Mode

Run the React development server with hot reload:

```bash
npm install
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Production Mode

1. Build the React app:
```bash
npm run build
```

2. Start the Express server:
```bash
npm run server
```

The server will run at [http://localhost:5000](http://localhost:5000)

### Quick Production Build & Run

```bash
npm run dev
```

## 🚀 Deployment

Deployed on **Vercel** with automatic deployments from the main branch.

### Manual Deployment

1. Build the production bundle:
   ```bash
   npm run build
   ```

2. Deploy the `build` folder and `server.js` to your hosting platform

3. Set environment variables on your hosting platform

4. Start the server:
   ```bash
   node server.js
   ```
